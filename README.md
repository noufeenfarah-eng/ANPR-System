# 🚗 Automatic Number Plate Recognition (ANPR)

An AI-powered Automatic Number Plate Recognition (ANPR) system built using YOLO, OpenCV, and EasyOCR.

## Features

✅ License plate detection using YOLO  
✅ OCR text extraction using EasyOCR  
✅ Plate text cleaning and correction  
✅ Works on single image input  
✅ Folder batch processing  
✅ Real-time webcam support  
✅ CSV logging for detected plates  

---

## Tech Stack

- Python
- OpenCV
- YOLO (Ultralytics)
- EasyOCR
